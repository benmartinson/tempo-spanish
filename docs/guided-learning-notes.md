# Guided Learning Notes

No Supabase migration is included for this batch.

The app works best with a curated `learning_passage` course. When that table is
empty or unavailable, it derives Spanish guided passages from `top_verb_video`
and then falls back to Spanish `video` rows when cached verb matches are sparse.
User progress first attempts to save to Supabase and falls back to device
storage when the progress table is absent.

Build or refresh the curated course with:

```bash
python3 scripts/build_guided_learning_passages.py --create-tables --write
```

The script reads every `top_verb_video` row, reconstructs the passage from
`transcript_segment`, asks OpenAI to judge the passage, and writes 200 ordered
Spanish rows to `learning_passage`. It requires `EXPO_PUBLIC_SUPABASE_URL`,
`SUPABASE_SERVICE_ROLE_KEY`, `OPENAI_API_KEY`, and `SUPABASE_DB_URL` or
`DATABASE_URL` when `--create-tables` is used.

If a DB URL is not available, print the exact SQL and run it manually in
Supabase first:

```bash
python3 scripts/build_guided_learning_passages.py --print-create-sql
```

Optional tables the app will use when present:

```sql
-- Optional source table for hand-curated or backfilled course order.
create table learning_passage (
  id bigint generated by default as identity primary key,
  language text not null default 'es',
  top_verb_video_id bigint null,
  video_id bigint not null,
  verb_id bigint null,
  level_band text not null,
  rank_order integer not null,
  skill_focus text not null default 'guided practice',
  start_segment_id integer null,
  end_segment_id integer null,
  quality_score numeric null,
  interest_score integer null,
  clarity_score integer null,
  proper_noun_load integer null,
  learner_value_score integer null,
  estimated_cefr text null,
  verb_tier integer null,
  word_count integer null,
  passage_preview text null,
  evaluator_model text null,
  evaluator_json jsonb null,
  updated_at timestamptz not null default now(),
  created_at timestamptz not null default now()
);

-- Optional per-user progress table.
create table user_learning_passage_progress (
  id bigint generated by default as identity primary key,
  user_id text not null,
  language text not null default 'es',
  source_key text not null,
  passage_id bigint null,
  status text not null,
  confidence integer null,
  started_at timestamptz null,
  completed_at timestamptz null,
  skipped_at timestamptz null,
  updated_at timestamptz not null default now(),
  unique (user_id, source_key)
);
```

Simple SQL-only fallback backfill shape, if you want a non-AI temporary course:

```sql
insert into learning_passage (
  language,
  top_verb_video_id,
  video_id,
  verb_id,
  level_band,
  rank_order,
  skill_focus,
  start_segment_id,
  end_segment_id
)
select
  'es',
  tvv.id,
  tvv.video_id,
  tvv.verb_id,
  coalesce(nullif(tvv.difficulty, ''), v.difficulty, 'lower intermediate'),
  row_number() over (
    partition by coalesce(nullif(tvv.difficulty, ''), v.difficulty, 'lower intermediate')
    order by tvv.count desc nulls last, tvv.id
  ),
  'verb forms',
  tvv.start,
  tvv.end
from top_verb_video tvv
join video v on v.id = tvv.video_id
where not exists (
  select 1
  from learning_passage lp
  where lp.top_verb_video_id = tvv.id
);
```
